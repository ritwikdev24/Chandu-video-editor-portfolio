# Purna Chandra Koppisetti — Senior Video Editor Portfolio

A premium, award-quality portfolio website for Senior Video Editor Purna Chandra Koppisetti, built with TanStack Start (React 19), Tailwind CSS v4, Framer Motion, and backed by a Netlify managed Postgres database.

## Features

- Cinematic dark theme with gold accents and glassmorphism design
- Animated hero with canvas particle system
- Filterable portfolio section with YouTube modal player
- Animated stats counter (9+ years, 5000+ videos, etc.)
- Vertical animated experience timeline
- Skills section with animated progress bars
- Contact form stored to Netlify Database
- Admin dashboard at `/admin` (password: `PCK@admin2026`)
- Loading screen, animated cursor, scroll progress bar, back-to-top button
- Fully responsive — mobile, tablet, desktop

## Tech Stack

- **Framework**: TanStack Start + React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Database**: Netlify Database (Postgres) via Drizzle ORM
- **Deploy**: Netlify

## Running Locally

```bash
npm install
netlify dev
```

Visit `http://localhost:8889`

## Admin Panel

Navigate to `/admin` and enter password `PCK@admin2026` to access the dashboard.
